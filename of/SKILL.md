In-flight is not done: while any residual is MISSING, `of status` / `of resume` print `running` + the live `PULSE` + a `speak` line (`quote a PULSE line above to the user; do not claim done while running`). Before ending a turn or saying the mission is done, run one of them and quote the live PULSE — the human never runs `of pulse` by hand. Follow the sibling.

Close is proof: the sibling names [docs/close-is-proof.md](../docs/close-is-proof.md). Residual empty is not the close. Successful close is not ACTIVE / not ALIVE.

When `of resume` prints `INTEGRATE --RECOMPUTE`, the wave report digest drifted: run `of integrate --wave N --recompute`. Do not next-wave.
